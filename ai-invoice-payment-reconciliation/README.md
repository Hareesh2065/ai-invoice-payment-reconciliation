# AI Agent for Intelligent Invoice and Payment Reconciliation

An educational Agentic AI prototype for matching invoice records, bank statement entries, and internal payment records; investigating discrepancies; and proposing evidence-backed resolutions for human review.

## Current status

**Milestone 1 — Working backend starter.** Includes FastAPI endpoints, synthetic demo data, deterministic reconciliation, a transparent tool-using investigation workflow, independent balance verification, and starter automated tests. The workflow is deterministic at this stage; LLM integration is planned for a later milestone.

## Features in this starter

- Validate invoice, bank transaction, and payment input using Pydantic.
- Calculate paid totals and outstanding balances.
- Flag potential duplicate invoice/payment records.
- Identify transactions not strongly linked to invoices.
- Record investigation tool calls and verification results.
- Interactive API documentation via FastAPI Swagger UI.

## Run locally

Requires Python 3.11 or newer.

```bash
python -m venv .venv
# Windows PowerShell
.venv\\Scripts\\Activate.ps1
# macOS/Linux instead: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Open http://127.0.0.1:8000/docs. Call `GET /demo-data`, then send its response to `POST /reconcile`.

Run tests:

```bash
pytest -q
```

## API endpoints

- `GET /` — project status
- `GET /health` — health check
- `GET /demo-data` — synthetic sample records
- `POST /reconcile` — reconciliation and investigation

## Safety

Use synthetic or otherwise authorized data only. This prototype does not connect to a bank, transfer funds, or post accounting adjustments. Findings are recommendations for human review. Financial arithmetic is performed using Python `Decimal`, not generated by an LLM.
